# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Report security issues privately to the maintainer through GitHub security advisories or direct contact through the repository owner profile:
- https://github.com/channor

Please include:
- a clear description of the issue
- affected package version or commit
- reproduction steps or proof of concept
- any suggested mitigation if available

You will receive confirmation when the report has been reviewed.
